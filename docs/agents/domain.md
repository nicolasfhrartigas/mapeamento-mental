# Documentação de domínio

## Antes de explorar

Ler `CONTEXT.md` na raiz ou `CONTEXT-MAP.md`, se existir, e ADRs relevantes em `docs/adr/`. Se não existirem, seguir sem sinalizar a ausência.

## Estrutura

Este é um repositório de contexto único: o glossário fica em `CONTEXT.md` e decisões de arquitetura ficam em `docs/adr/`.

## Vocabulário

Usar a terminologia definida no glossário ao nomear conceitos. Quando uma decisão conflitar com ADR existente, tornar o conflito explícito.
