# Rótulos de triagem

| Papel da skill | Rótulo no rastreador | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Manutenção precisa avaliar a issue. |
| `needs-info` | `needs-info` | Aguarda mais informações da pessoa relatora. |
| `ready-for-agent` | `ready-for-agent` | Especificada e pronta para agente AFK. |
| `ready-for-human` | `ready-for-human` | Requer implementação humana. |
| `wontfix` | `wontfix` | Não será realizada. |
